## 4. 题目内容

我是一个供应商，帮我做一个昆山飘得华电子材料有限公司产品客户管理系统，只要一个HTMl，但是具备所有的功能。要有监控界面，数据管理界面，操作日志界面，数据管理界面负责编辑更改数据表的所有内容和加减表格列的功能，操作日志界面可以将操作界面的误删操作选择点击返回上一步。监控界面要做成类似图2这样的，然后要产品客户数据，我点击某客户就出现弹窗显示客户用的所有产品和产品详细数据，点击该产品就会出现使用的客户和产品详细数据。操作管理界面要可以更改列的名称。操作日志界面可以针对某一操作我点击然后进行恢复此操作返回上一步功能。美化各个界面增加更多的功能。监控界面要有详细的产品客户数据，美化各个界面.将该HTML命名为昆山飘得华电子材料有限公司产品客户管理系统，并且不影响任何功能使用。另外在数据管理界面增加导出excel功能，增加导入excel功能使导入的文件数据与系统的一一对应，并且如果出现重复的，将自动以excel文件的为准将系统里面的数据进行更新。增加操作日志界面针对某一个操作我可以进行返回上一步或者进行恢复该操作。数据管理界面删除列以后，只是删除对应该列的第一行，并没有将该整列都删除。数据管理界面添加列以后，只是添加该列对应该列的第一行，并没有将该整列都添加。数据管理界面增加小列，类似图3这样的。在数据管理界面，添加列的功能添加子列里面不只是药水分析项目，我可以添加任意子列，且添加的子列必须在父列下面，类似图片那样。在操作日志界面增加恢复功能，我可以选择恢复任意一步操作，同时恢复以后该操作还原到监控界面和数据管理界面，将之前的操作还原，而监控界面和数据管理界面也会跟着这个操作还原。并且保证任何数据无异常，所有功能正常使用。

## 6. 功能清单

- **监控界面**：数据统计、客户列表（点击查看产品及详情）、产品列表（点击查看客户及详情）
- **数据管理**：表格编辑、添加/删除整行、添加/删除整列、父子列、修改列名、导出/导入 Excel
- **操作日志**：操作历史、恢复任意步骤（同步还原监控与数据管理界面）
